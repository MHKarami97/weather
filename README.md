# هواشناسی (weather)

وضعیت لحظه‌ای و پیش‌بینی آب‌وهوای ۳۱ استان ایران - PWA با Vue 3 روی GitHub Pages، با داده‌ی [Windy Point Forecast API](https://api.windy.com/point-forecast/docs). ظاهر و ساختار از پروژه‌ی «نرخ» گرفته شده است.

## امکانات
**صفحه‌ی اول**
- علاقه‌مندی‌ها (پیش‌فرض: تهران، کرج/البرز، مشهد/خراسان رضوی، اصفهان) + کارت همه‌ی ۳۱ استان و جستجو
- هر کارت: دما، وضعیت هوا، دمای محسوس، باد، رطوبت، فشار، کمینه/بیشینه‌ی امروز، بارش ۲۴ ساعت، ابر
- بالای صفحه: زمان آخرین دریافت داده

**صفحه‌ی جزئیات استان** (کلیک روی کارت)
- وضعیت لحظه‌ای: دمای محسوس، رطوبت، باد (با جهت)، فشار، ابر (۳ لایه)، بارش، ناپایداری (CAPE)، طلوع/غروب
- ساعت‌های آینده
- گزارش‌های کاربردی: پوشش، چتر، هشدار باد/گرما/سرما/یخبندان/مه/رعد، بهترین زمان فعالیت بیرون، خشک‌شدن لباس، روند فشار، نیاز گرمایش/سرمایش، کیفیت هوا و گردوخاک، روزهای بارانی و ...
- نمودارها (۲۴ ساعت / ۴۸ ساعت / ۷ روز / همه): دما، بارش، باد، رطوبت، ابر، فشار، CAPE
- کیفیت هوا (CAMS): AQI، PM2.5، PM10، گردوخاک، گازها
- پیش‌بینی روزانه (کارت‌ها + نمودار)

## معماری
```
GitHub Action (هر ۱ ساعت)  →  scripts/fetch-weather.mjs  →  Windy API
        └─ خروجی در شاخه‌ی data (یک کامیت، force-push):  latest.json + provinces/<id>.json
مرورگر  →  raw.githubusercontent.com/<repo>/data/...  (پشتیبان: /data/ هم‌دامنه)
```
- شاخه‌ی `data` هر ساعت با یک کامیت تازه جایگزین می‌شود، پس داده‌ی قدیمی در ریپو نمی‌ماند.
- اگر دریافت یک استان شکست بخورد، آخرین فایل معتبر همان استان حفظ می‌شود.
- با تغییر داده نیازی به build مجدد سایت نیست.

## راه‌اندازی
1. ریپو را روی GitHub بسازید و کد را در شاخه‌ی `main` push کنید.
2. Settings → Secrets and variables → Actions → New repository secret: نام `WINDY_API_KEY` و مقدار کلید Windy.
3. Settings → Actions → General → Workflow permissions: «Read and write permissions».
4. Actions → «Refresh Weather Data» → Run workflow (یک‌بار دستی) تا شاخه‌ی `data` ساخته شود.
5. Settings → Pages → Source: GitHub Actions.
6. اگر سایت روی زیرمسیر است (`user.github.io/weather`): Settings → Variables → `VITE_BASE` = `/weather/`.
7. آیکون‌های PNG را در `public/icons/` بگذارید (نام‌ها در README همان پوشه).
8. (اختیاری) فونت‌های `Vazirmatn-*.woff2` را از پروژه‌ی نرخ به `public/fonts/webfonts/` کپی کنید؛ وگرنه از CDN لود می‌شود.

## توسعه‌ی محلی
```bash
npm install
npm run test:logic                                           # تست منطق بدون API
WINDY_API_KEY=xxxx OUT_DIR=public/data npm run fetch-data    # داده‌ی واقعی برای dev
npm run dev
```

## نکته‌ها
- مدل `gfs` برای مختصات مرکز هر استان؛ گام زمانی معمولاً ۳ ساعته است و بارش هر نقطه مجموع همان گام است.
- هر اجرا ≈ ۶۲ درخواست به Windy می‌زند (۳۱ آب‌وهوا + ۳۱ کیفیت هوا) و روزانه ≈ ۱۴۸۸. اگر سقف کلیدتان کمتر است، `WINDY_AQ` را در workflow روی `'0'` بگذارید.
- شاخه‌ی `data` برای خواندن از raw باید عمومی باشد (ریپوی public).
